

* `skills/` contains the skill files. skill files are meant to be loaded depending on the tasks. Can be loaded explictly with `/agent-skills:<skill-name` or let the agent load it as needed.
* `commands/` contains slash commands that can be invoked. it is meant to be a pre-typed commands that can be used to start or trigger a certain commands. most commands here will produce artifacts to be worked on at a later step.
